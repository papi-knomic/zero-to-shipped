The problem

Expired paperwork is expensive.

A typical small business holds a dozen documents that quietly expire: tax clearance and company filings, fire safety certificates, insurance policies, premises permits and leases. The dates are buried in PDFs and phone scans, nobody owns the calendar, and one missed renewal can mean a fine, a sealed shop or an uninsured loss.

01

Dates hide in documents

Some documents print an expiry date. Others only say “valid for twelve months from the date of issue”, and someone has to do the maths.

02

Nobody owns the calendar

Renewals come round once a year, often long after whoever filed the paperwork has moved on to other work.

03

Lapses cost real money

Penalties, lost contracts that require valid certificates, and claims refused because the cover had already lapsed.

How it works

Four steps, then you can forget about it.

  1. 1

    Upload

    Drop in a PDF or a photo. It goes straight to private storage through a short-lived upload link.

  2. 2

    Lapse reads it

    Amazon Textract finds the document type, issuer, parties and every date, along with the exact line each date came from. “Valid for 12 months” becomes an expiry date, calculated in code rather than guessed.

  3. 3

    You confirm

    Nothing is scheduled until you’ve checked the details against the document and fixed anything that’s off.

  4. 4

    Reminders go out

    Email reminders 60, 30 and 7 days before expiry, plus an in-app feed so nothing is missed if an email is.

Architecture

Serverless on AWS. Nothing runs while it’s idle.

Every component is pay-per-use, defined in Terraform and deployed to us-east-1. Each Lambda function has its own least-privilege IAM role. 

Browser ─► API Gateway (HTTP API) ─► Lambda ─► DynamoDB
Browser ─► S3 (presigned upload) ─► SQS ─► Lambda ─► Textract ─► DynamoDB
EventBridge Scheduler ─► Lambda ─► SES email + in-app feed
Amazon API Gateway + AWS Lambda
HTTP API with one Node.js 22 function per route on Graviton (arm64).
Amazon S3 + SQS
Private document storage. Browsers upload directly with presigned URLs; each upload is queued for extraction, two at a time, with a dead-letter queue.
Amazon Textract
AnalyzeDocument Queries ask each document for its type, issuer, holder and dates. Every answer has a confidence score and a quote of the line it came from. DD/MM dates and phrases like “valid for twelve months” are interpreted in code, not by a model.
Amazon DynamoDB
Single-table design with on-demand capacity and point-in-time recovery.
Amazon EventBridge Scheduler
One-time schedules for each reminder, deleted automatically after they fire.
Amazon SES
Reminder emails with bounce and complaint suppression, also recorded to an in-app notification feed.
Amazon CloudWatch + AWS X-Ray
Structured logs, traces and custom metrics through Powertools for AWS Lambda, with a dashboard and alarms.
Terraform
All infrastructure as code. State is kept in S3 with native locking.
